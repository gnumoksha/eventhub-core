# Finance

Finance bounded context (supporting subdomain).

Manages the money the platform holds on behalf of organizers: fee policies (convenience and service fees), a double-entry ledger, the organizer balance and payouts (*repasses*). Funds are released for payout only some days after the event finishes, to cover cancellations and chargebacks.

See [bounded_contexts.md](../../var/docs/bounded_contexts.md#finance).
